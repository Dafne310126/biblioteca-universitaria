
# Biblioteca Universitaria del Saber

## Descripción
Este proyecto consiste en un sitio web multipágina
desarrollado con Flask, HTML, Jinja2 y Bootstrap.

Su objetivo es presentar información general de una
biblioteca universitaria, sus materiales, servicios y contacto.

## Tecnologías utilizadas
- Python: lenguaje utilizado para programar el servidor.
- Flask: herramienta para crear las rutas de la aplicación.
- HTML: estructura y contenido de las páginas.
- Jinja2: sistema de plantillas y herencia.
- Bootstrap: diseño y navegación.
- GitHub: alojamiento del repositorio del proyecto.

## Archivos del proyecto
- `server.py`: contiene las cuatro rutas de Flask y envía
  las variables titulo y mensaje.
- `templates/layout.html`: contiene la estructura general
  y el menú de navegación compartido.
- `templates/index.html`: presenta la información de inicio.
- `templates/catalogo.html`: describe las categorías de materiales.
- `templates/servicios.html`: explica los servicios disponibles.
- `templates/contacto.html`: muestra los medios de contacto.
- `requirements.txt`: indica la dependencia Flask.

## Instalación y ejecución
1. Instalar Python.
2. Instalar Flask con `python -m pip install Flask`.
3. Abrir una terminal en la carpeta del proyecto.
4. Ejecutar `python server.py`.
5. Abrir `http://127.0.0.1:5000` en el navegador.
